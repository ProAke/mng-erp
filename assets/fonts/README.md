# ฟอนต์ภายในระบบ

- **Prompt** (Regular, Medium, SemiBold, Bold): [google/fonts](https://github.com/google/fonts/tree/main/ofl/prompt), สัญญาอนุญาต `OFL.txt`
- **Noto Emoji** (WOFF2, Regular): [@fontsource/noto-emoji 5.3.2](https://www.npmjs.com/package/@fontsource/noto-emoji), สัญญาอนุญาต `OFL-NotoEmoji.txt`

ใช้เป็น fallback เมื่อเครื่องหรือเครือข่ายไม่สามารถโหลดฟอนต์ภายนอกได้ โดยอุปกรณ์ที่มีฟอนต์อีโมจิสีจะใช้ฟอนต์ของอุปกรณ์ก่อน
